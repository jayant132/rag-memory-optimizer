# Corporate Security and Remote Access Policy v4.2
Last Updated: January 2026
Applies to: All Full-Time Employees and Contractors

## 1. Data Governance & Storage
1.1 All proprietary source code, customer records, and financial projections must remain strictly within approved company cloud environments.
1.2 Local caching of unencrypted enterprise data on personal devices (BYOD) is strictly prohibited under Section 8.4 of the Master Compliance Agreement.

## 2. Authentication & Network Access
2.1 Multi-Factor Authentication (MFA) via hardware security keys or authenticator apps is mandatory for all production cluster access.
2.2 VPN tunnels must be active when querying internal knowledge bases from outside corporate subnetworks.

## 3. Incident Response Protocol
3.1 Any suspected data leak or unauthorized token extraction must be reported to the Security Operations Center (SOC) within 1 hour of discovery.
